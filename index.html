How It Works

From profile creation to mentorship match in three steps

Step 1 ~5 min

Create Profiles

Mentors and learners create rich YAML profiles with skills, interests, availability, career goals, and communication preferences.

  1. Skills: Select from standardized STEM taxonomy (programming, data science, ML, etc.)
  2. Availability: Define timezone, hours/week, preferred meeting formats
  3. Goals: Specify career objectives, learning targets, mentorship style
  4. Preferences: Communication style, meeting frequency, feedback approach
YAML Schema
  • Validation
    • Step 2 ~10 sec

    Run Matching

    Execute the compatibility algorithm to find optimal mentor-learner pairs based on weighted scoring criteria.

    1. Skills Overlap: Jaccard similarity on skill sets (30% weight)
    2. Career Alignment: Goal compatibility scoring (25% weight)
    3. Availability Match: Timezone + schedule overlap (20% weight)
    4. Communication Style: Preference alignment (15% weight)
    5. Goals Alignment: Objective compatibility (10% weight)
    Weighted Scoring Configurable
    Step 3 ~2 min

    Review & Connect

    Review top matches, export results, generate mentorship agreements, and initiate the connection.

    1. Review: Examine top-3 matches with detailed score breakdowns
    2. Export: Generate CSV/JSON reports for program administrators
    3. Agreement: Auto-generate mentorship agreement templates
    4. Connect: Share contact info and schedule first meeting
